# FX to Vector

Figma plugin for converting layer effects to vectors for easier transport between programs.

Capabilities:

- Drop shadows
- Inner shadows

Other available effects:

- Layer blur
  - Not convertable in a useful way
- Background blur
  - Same as layer blur
- Noise
  - Not convertable in a way that retains full vector capabilities, could be rasterized
- Texture
  - Same as noise
- Glass
  - Same as layer blur
